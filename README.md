# Priinteve Innovations

Marketing website for **Priinteve Innovations** — *Print any thing, anywhere, on demand.*

The site presents Priinteve's products (Xerox Buddy, Vantadot, Salony, Nectcard, Priinteve Printing), services (websites, custom web apps, WhatsApp/Telegram bots, AI agents and business automation), case studies, FAQ, legal pages, and enquiry/waitlist forms.

Live: [priinteve.com](https://priinteve.com)

## Tech stack

- [Next.js 16](https://nextjs.org) (App Router) + React 19 + TypeScript
- [Tailwind CSS 4](https://tailwindcss.com)
- [Framer Motion](https://motion.dev) and [Lenis](https://lenis.darkroom.engineering) for animation and smooth scrolling
- [three.js](https://threejs.org) via [@react-three/fiber](https://r3f.docs.pmnd.rs) for 3D scenes
- [lucide-react](https://lucide.dev) icons

## Getting started

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Scripts

| Command             | Description                        |
| ------------------- | ---------------------------------- |
| `npm run dev`       | Start the development server       |
| `npm run build`     | Create a production build          |
| `npm start`         | Serve the production build         |
| `npm run typecheck` | Type-check with `tsc --noEmit`     |
| `npm run lint`      | Lint with ESLint                   |

## Project structure

```
src/
  app/            Routes (home, about, products, services, work, faq, contact, legal/policy pages),
                  plus sitemap, robots, icons and Open Graph image
  components/
    case-studies/ Work/case-study showcase and lists
    forms/        Enquiry and waitlist forms
    layout/       Header, footer, logo, theme toggle, preloader
    motion/       Scroll and reveal animation primitives
    products/     Product cards, mockups and showcases
    sections/     Page sections (hero, lists, legal pages)
    services/     Service cards and groups
    three/        3D canvases and scenes
    ui/           Shared UI primitives, JSON-LD, page hero
  content/        Site copy and data (site info, navigation, products, services, work, pages, blocks, faq, legal)
  lib/            Helpers (SEO, form submission, scroll/CSS-var hooks, utils)
public/           Static assets
legacy-static/    Previous static-HTML version of the site (generated by build.mjs)
```

## Editing content

Most copy lives in [`src/content/`](src/content):

- `site.ts` — company name, contact details, tagline, enquiry options
- `products.ts`, `services.ts`, `work.ts` — product, service and case-study data
- `navigation.ts`, `pages.ts`, `blocks.ts` — menus and page copy
- `faq.ts`, `legal.ts` — FAQ and legal/policy content

Text in `[square brackets]` is treated as a placeholder awaiting confirmation and is rendered as such.

## Forms

Form submission goes through a single function, `submitForm` in [`src/lib/forms.ts`](src/lib/forms.ts). There is currently no backend: submissions are validated and the user is given a pre-filled `mailto:` link. To deliver submissions directly, POST the fields to a route handler, server action or CRM there and return `delivered: true`.
